# PLACEHOLDER workspace – javascript-foundations

This is **not** the real `javascript-foundations` starter workspace. The image was built from
a checkout without `workspaces/javascript-foundations/` (the JavaScript course stream was not
merged yet), so `images/tutor-lab/seed-fallback/javascript-foundations/` was seeded instead.

It exists so the image, the tutor panel and the smoke test have something to run and open.
Rebuild the image from a checkout that contains `workspaces/javascript-foundations/` and this
file disappears (the seed script logs `PLACEHOLDER` when it is used).

Layout mirrors the spec (Addendum A4): `node --test`, one file per step under
`exercises/<step>.test.js`, no reference solutions, no dependencies.
