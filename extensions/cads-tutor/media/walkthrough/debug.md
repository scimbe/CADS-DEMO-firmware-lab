# Debuggen / Debug

- **F5** startet „Debug CaDS Zero (Board im Browser)“ (cortex-debug, GDB-Server der Board-Bridge auf 127.0.0.1:3333).
- Breakpoint setzen: Klick links neben die Zeilennummer. Stepping mit F10/F11, Register und Peripherie (SVD) in der Debug-Seitenleiste.
- Der Tutor erkennt Debug-Stops für seine Checks automatisch.

---

- **F5** starts “Debug CaDS Zero (board in browser)” (cortex-debug via the Board-Bridge GDB server on 127.0.0.1:3333).
- Set a breakpoint by clicking left of a line number. Step with F10/F11; registers and peripherals (SVD) are in the debug sidebar.
- The tutor detects debug stops for its checks automatically.
