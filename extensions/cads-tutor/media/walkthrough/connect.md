# Board verbinden / Connect the board

1. ST-Link (Nucleo-Board) per USB an **deinen** Rechner anschließen.
2. Command Palette → **CaDS Board: Connect** (`cads.board.connect`). Der Browser fragt nach dem USB-Gerät – *STM32 STLink* auswählen.
3. In der Statusleiste erscheint der Board-Status (verbunden / angehalten).

---

1. Plug the ST-Link (Nucleo board) into **your** computer via USB.
2. Command Palette → **CaDS Board: Connect**. The browser asks for the USB device – choose *STM32 STLink*.
3. The status bar shows the board state (connected / halted).
