# Extra grounding sources

The tutor grounds "Ask the tutor" on the `javascript` content pack of the
tutor platform, which carries seven chapters of the MDN *JavaScript Guide*:
Introduction, Grammar and types, Control flow and error handling, Loops and
iteration, Functions, Working with objects, Indexed collections.

Modules M6 (asynchrony) and parts of M2 and M5 go beyond that pack. The three
Markdown files next to this README are the MDN guide pages for those topics,
fetched from `mdn/content` (branch `main`) on 2026-09-03 and reproduced under
**CC-BY-SA 2.5**, Mozilla and individual contributors. Each file carries its own
source URL and licence note in its header.

| File | MDN page |
|---|---|
| `mdn-using-promises.md` | [Using promises](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Using_promises) |
| `mdn-javascript-modules.md` | [JavaScript modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules) |
| `mdn-using-classes.md` | [Using classes](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Using_classes) |

The tutor chunks and indexes `sources/**.md` in addition to the pack, and cites
them as "JavaScript Foundations". Nothing here is rewritten or summarised: the
grounding corpus has to be the real documentation, not a paraphrase of it.
